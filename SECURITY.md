# Security Policy

## Reporting a vulnerability

Please do not publish exploit details in a public Issue. Use GitHub's private vulnerability reporting for this repository when available. Include the affected version, operating system, steps to reproduce, and the impact you observed. Do not attach personal resumes, job records, or database files.

## Scope

The application processes local files and public job pages. Reports involving unsafe URL handling, local data exposure, file parsing, Tauri IPC permissions, or SQL persistence are especially helpful.
