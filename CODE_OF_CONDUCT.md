# Community Guidelines

Participation in this project is expected to be respectful, specific, and constructive.

- Critique code and ideas without personal attacks or discriminatory language.
- Share technical context needed to reproduce a problem while removing private resumes, job records, tokens, and local file paths.
- Accept review feedback and keep discussions focused on the project.
- Maintainers may remove abusive, harassing, or privacy-invasive content from project spaces.

Report conduct concerns privately through the repository owner's GitHub profile.
